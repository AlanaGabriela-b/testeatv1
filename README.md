# Aplicação de Feedbacks

Esta aplicação coleta feedbacks de alunos utilizando um servidor Express simples e armazena os dados em memória.

## Como adicionar um arquivo ao Git

1. Verifique o estado atual do repositório:
   ```bash
   git status
   ```
2. Adicione o arquivo desejado à área de staging (substitua `arquivo.ext` pelo nome do arquivo real):
   ```bash
   git add arquivo.ext
   ```
3. Confirme que o arquivo entrou em staging:
   ```bash
   git status
   ```
4. Registre a alteração com uma mensagem de commit:
   ```bash
   git commit -m "Mensagem descritiva"
   ```
5. (Opcional) Envie o commit para o repositório remoto:
   ```bash
   git push
   ```

Esses passos permitem colocar um arquivo sob controle de versão no Git e registrar as mudanças realizadas.
